## 一、补实验结果

### §五 Budget ablation 补充:B0 vs B2,Movies+Grocery × seeds 42/43/44

新增 8 runs(seed42 复用,driver `--seeds 43,44`),位置 `outputs/p1/budget_ablation/`:

| Dataset | B2−B0 val(seed 42 / 43 / 44) | 结论 |
|---|---:|---|
| Movies | −0.72% / +0.15% / −0.57% | B0 略优(2/3 seeds) |
| Grocery | +0.26% / +0.41% / −0.32% | B2 略优(2/3 seeds) |

**结论:B0 ≈ B2(±0.7% 内,无一致赢家)。** seed42 的 Movies B0>B2 在 2/3 seeds 复现但幅度小;budget 的性能贡献不显著,**保留理由是机制价值(Factor-dependent Graph Demand)而非精度**。

## 二、补的指标

### §十一/§十二 Edge-level relation specialization

新增 `S_R = 1 − H_R/ln(K)`(H_R = `rel_edge_entropy`,代码原有)。K_eff 只排除全局 occupancy collapse;S_R 排除 per-edge uniform collapse。已写入:
- `summarize_p1.py`:`rel_specialization` 列(p1_{screen,confirm,budget_ablation}_mechanism.csv)+ 报告 Mechanism 表 H_R/S_R 列
- 无需重跑,从既有 checkpoint 诊断数据计算

F1R1,seeds 42/43/44 结果:

| Dataset | S_R(42/43/44) | 判定 |
|---|---|---|
| Grocery | 0.36 / 0.46 / 0.33 | 实质 edge-level specialization |
| ele-fashion | 0.29 / 0.27 / 0.34 | 同上 |
| Movies | 0.26 / 0.24 / 0.25 | 中等 |
| Toys | 0.33 / 0.16 / 0.27 | 中等 |
| **Reddit-S** | **0.07 / 0.01 / 0.02** | **per-edge 近 uniform,decomposition 几乎未学到结构** |

→ Reddit-S 的 K_eff≈3.9 看似健康但 S_R≈0;这也解释了 selector 在该图的退化。**今后 S_R 与 K_eff 一起报告。**
