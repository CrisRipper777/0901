# 十二、建议补一个“不需要重新训练”的 post-hoc diagnostic

从现有 OFR checkpoints 直接构造 effective operator：

Tfk.T_{fk}.

Ifk=Tfk−Tˉf⋅−Tˉ⋅k+Tˉ⋅⋅.\boxed{ I_{fk} = T_{fk} - \bar T_{f\cdot} - \bar T_{\cdot k} + \bar T_{\cdot\cdot}. }

Tˉf⋅=1K∑kTfk,\bar T_{f\cdot} = \frac1K\sum_kT_{fk},Tˉ⋅k=1F∑fTfk,\bar T_{\cdot k} = \frac1F\sum_fT_{fk},Tˉ⋅⋅=1FK∑f,kTfk.\bar T_{\cdot\cdot} = \frac1{FK}\sum_{f,k}T_{fk}.

# 十五、OFR 冻结为 final operator：可以，但要明确它是什么意义上的 final

当前 Val 规则下：

OFR>O0OFR>O0

五个数据集 mean 都为正，而且 3/5 是五种 full variants 中最优。

所以作为：

validation-selected performance configuration\boxed{\text{validation-selected performance configuration}}

冻结 OFR 是合理的。

但不能说：

OFR proves pair-specific interaction is necessary\boxed{ \text{OFR proves pair-specific interaction is necessary} }

因为：

1. OFR 比 OADD 多 196K 参数；
2. full decomposition 不可辨识；
3. parameter-matched LR interaction 没有收益；
4. OFR−OADD 的平均增益其实只有约：

0.09 pp0.09\text{ pp}

跨五数据集平均。

因此最终建议称它：

Full Cell-conditioned Operator\boxed{ \textbf{Full Cell-conditioned Operator} }

而不是在论文主文反复叫：

> Full Interaction Operator。

# 二十、还想做“最后一个 P3 积木”，推荐一个

不是 FiLM，也不是再加 MoE。

我只认为下面这个值得：

Basis-decomposed Cell Operator\boxed{ \textbf{Basis-decomposed Cell Operator} }

也就是 R-GCN 风格的成熟 basis decomposition 思路：

Tfk=W0+∑b=1BcfkbVb\boxed{ T_{fk} = W_0+ \sum_{b=1}^{B} c_{fkb}V_b }

其中：

Vb∈Rd×dV_b\in\mathbb R^{d\times d}

是 **full matrix basis**，

cfkbc_{fkb}

是每个 Factor×Relation cell 的 coefficient。

------

## 为什么它比你现在 Low-rank 更值得测试？

你现在是：

UDiag⁡(cfk)V⊤U\operatorname{Diag}(c_{fk})V^\top

即所有 cell 都共享 rank-1 basis：

ujvj⊤.u_jv_j^\top.

而 basis operator 使用：

V1,…,VBV_1,\ldots,V_B

这些本身就是任意 full-rank matrices。

所以它能回答：

> P3-B 失败究竟是因为 cell operator 真需要 311K 参数，还是因为 `U diag(c) V^T` 这个 shared low-rank subspace 太 restrictive？
